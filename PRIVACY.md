# QuietShield privacy policy

QuietShield does not collect, store, sell or transmit any personal data or browsing data.

- All filtering happens locally in your browser using rules bundled with the extension.
- Settings (on/off per site, blocking mode) are saved with `chrome.storage` on your device only.
- QuietShield contains no analytics, telemetry or ads.
- **Update check (GitHub installs only):** once a day, the extension requests
  `https://api.github.com/repos/arjun-vegeta/QuietShield/releases/latest` to see whether a newer
  version exists. No cookies or identifiers are sent; GitHub sees only what any web request
  includes (such as your IP address). You can turn this off in the popup. Copies installed from
  the Chrome Web Store never make this request — the store updates them.

Questions: open an issue at https://github.com/arjun-vegeta/QuietShield/issues
